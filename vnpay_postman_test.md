# VNPay Payment Integration Test Guide

## 1. Prerequisites

- Postman installed on your computer
- Backend server running on `http://localhost:5000`
- Frontend server running on `http://localhost:5173`
- Valid user account for testing

## 2. Environment Setup in Postman

1. Create a new environment in Postman named "VNPay Test"
2. Add the following variables:
   - `BASE_URL`: http://localhost:5000/api
   - `TOKEN`: (leave empty for now)

## 3. Test Collection

### 3.1. Login to Get Authentication Token

**Request:**

- Method: POST
- URL: {{BASE_URL}}/auth/login
- Headers:
  - Content-Type: application/json
- Body (raw JSON):

```json
{
  "email": "test-admin@gmail.com",
  "password": "admin123456"
}
```

**Test Script:**

```javascript
// Save auth token to environment
if (pm.response.code === 200) {
  var jsonData = pm.response.json();
  pm.environment.set("TOKEN", jsonData.token);
  console.log("Token saved:", jsonData.token);
} else {
  console.log("Error logging in:", pm.response.text());
}
```

### 3.2. Create VNPay Payment

**Request:**

- Method: POST
- URL: {{BASE_URL}}/payment/create
- Headers:
  - Content-Type: application/json
  - Authorization: Bearer {{TOKEN}}
- Body (raw JSON):

```json
{
  "amount": 10000,
  "orderDescription": "Test payment",
  "orderType": "other",
  "language": "vn",
  "items": [
    {
      "product": "507f1f77bcf86cd799439011", // Replace with a valid product ID from your database
      "quantity": 1,
      "price": 10000
    }
  ]
}
```

**Test Script:**

```javascript
// Check response and extract payment URL
if (pm.response.code === 200) {
  var jsonData = pm.response.json();
  if (jsonData.code === "00") {
    console.log("Payment URL:", jsonData.data);
    pm.environment.set("PAYMENT_URL", jsonData.data);
    pm.environment.set("ORDER_ID", jsonData.orderId);

    // Set visualization
    pm.visualizer.set(`
            <h3>VNPay Payment Test</h3>
            <p>Order ID: ${jsonData.orderId}</p>
            <p><a href="${jsonData.data}" target="_blank">Click here to open payment page</a></p>
            <p>Payment URL:</p>
            <textarea style="width: 100%; height: 100px">${jsonData.data}</textarea>
        `);
  } else {
    console.log("Error creating payment:", jsonData.message);
  }
} else {
  console.log("Error response:", pm.response.text());
}
```

## 4. Testing Flow

1. Execute the Login request to get an authentication token
2. Execute the Create VNPay Payment request
3. Copy the payment URL and open it in a browser
4. Complete the payment flow in the VNPay sandbox
5. VNPay will redirect back to your frontend app (http://localhost:5173/payment-return)

## 5. Common Issues and Troubleshooting

1. **Error code 70 (Dữ liệu gửi sang không đúng định dạng)**:

   - Check all parameter values and formats
   - Ensure the URL parameters are alphabetically ordered
   - Check vnp_ReturnUrl is properly encoded

2. **Authentication errors**:

   - Ensure token is valid and not expired
   - Check if the user has required permissions

3. **Order creation errors**:

   - Verify product IDs are valid MongoDB ObjectIDs
   - Ensure amount calculation is correct
   - Check request format matches backend expectations

4. **Return URL not working**:
   - Verify VNP_RETURNURL in .env file is correct
   - Ensure the route exists in your frontend app
